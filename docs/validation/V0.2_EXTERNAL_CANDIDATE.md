- Direct changed service: catalog.
- Downstream services: orders and gateway.
- Paths must be evidence-backed by the declared edges; catalog -> orders -> gateway and catalog -> gateway are both possible. The analyzer chooses one deterministic path.
- No additional services may be inferred.

For a historical commit changing ONLY services/orders/**:
- Direct changed service: orders.
- Downstream service: gateway.
- Catalog is an upstream dependency, not downstream impact.

For a historical commit changing ONLY services/gateway/**:
- Direct changed service: gateway.
- No downstream services declared.
